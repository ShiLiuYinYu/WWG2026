# 目录结构组织

```text
WWG/
├─ Assets/
│  ├─ Scenes/
│  │  ├─ Title.unity                # Build index 0，主菜单
│  │  ├─ S0.unity                   # S0 楼外
│  │  ├─ S0/                        # S0_Corridor / S0_ClubRoom / S0_Bridge
│  │  ├─ S1.unity                   # S1 夜间 5F 活动室
│  │  ├─ S1/                        # S1_Corridor / S1_BridgeEntrance
│  │  ├─ S2.unity                   # S2 单数栋 4F 入口
│  │  ├─ S2/                        # S2_BridgeSpan4F / S2_BridgeEven4F / S2_ClubRoom
│  │  ├─ S3.unity                   # S3 机房
│  │  └─ S4.unity                   # S4 终章活动室
│  ├─ Scripts/
│  │  ├─ Core/GameFlow.cs           # 场景名、Build Settings 校验及统一加载
│  │  ├─ UI/TitleMenuController.cs  # 主菜单按钮
│  │  ├─ Dialogue/                  # DialogueService、IDialogueContext、uGUI 呈现器、命令与函数
│  │  ├─ S0/                        # S0Controller / S0Hotspot
│  │  ├─ S1/                        # S1Controller / S1Hotspot
│  │  └─ S2/                        # S2Controller
│  ├─ Yarn/
│  │  ├─ WWG.yarnproject            # 唯一 Yarn 工程
│  │  ├─ Shared/                    # 公共声明与测试节点
│  │  └─ Chapters/                  # Prologue / NightPhoto / BridgeRoute
│  ├─ Editor/                      # 一次性迁移、脚手架、菜单接线、Yarn 校验
│  ├─ Resources/                   # Title、S0、S1 美术与音频
│  │  └─ Dialogue/                  # WwgDialogueHost 预制体与立绘配置
│  └─ Settings/                    # URP 2D 与场景模板（URP2DSceneTemplate）
├─ Document/
│  ├─ Program/                     # 本项目程序规范
│  ├─ Image/                       # 机制、系统、UI 草图
│  └─ *.md                         # 故事、Demo 剧本和制作记录
├─ Packages/manifest.json
├─ ProjectSettings/EditorBuildSettings.asset
├─ AGENTS.md
└─ .opencode/skills/unity-scene-workflow/SKILL.md
```

### 地点场景命名

| 章节 | 场景名 | 固定画面 |
| --- | --- | --- |
| S0 | `S0` | 实验楼外景 |
| S0 | `S0_Corridor` | 白天单数栋 5F 走廊 |
| S0 | `S0_ClubRoom` | 白天/熄灯时活动室 |
| S0 | `S0_Bridge` | 白天 4F 连廊入口 |
| S1 | `S1` | 夜间 5F 活动室，P1 |
| S1 | `S1_Corridor` | 夜间 5F 走廊 |
| S1 | `S1_BridgeEntrance` | 夜间单数栋 4F 连廊入口 |
| S2 | `S2` | 单数栋 4F，导览稿、海报与应急照明开关 |
| S2 | `S2_BridgeSpan4F` | 玻璃连廊中段，低 SAN 留言 |
| S2 | `S2_BridgeEven4F` | 偶数栋 4F，海报与资料柜 |
| S2 | `S2_ClubRoom` | 夜间 5F 安全屋视图 |
| S3 | `S3` | 3F 机房，P3 |
| S4 | `S4` | 5F 终章活动室 |

S0/S1/S2 使用章节入口与 `章节_地点.unity`，S3/S4 各有独立入口，并在 `GameFlow` 和 Build Settings 同时登记。S2 当前沿用 S1 夜景作背景；后续替换美术时要保留各地点的海报、玻璃与资料柜可交互层。场景对象的画面与热点可独立编辑，但 UI/控制器仍是各地点的副本；修改同章 UI 时应检查全部地点。对白文本不在场景或控制器里维护，统一编辑 `Assets/Yarn/Chapters/` 下对应章节的 `.yarn` 文件；`WwgDialogueHost` 只在首次进入章节时从 `Resources/Dialogue` 实例化一次。
