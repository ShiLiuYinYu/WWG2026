# 《熄灯之后：48H》后 24H 游戏流程策划书

> 制作提案 v1 · 周六 16:05 至周日 16:00 · 目标游玩时长 21–28 分钟

## 1. 接续前 24H

周六下午，旧工程刚把主角标为「缺席」。四个人都还在 5F 活动室，林未的工牌收在纪念盒里，桌上放着机房借用便签和装有她备份的 U 盘。袁祁想在第二次熄灯前弄清要防什么，唐澈想找出「缺席」是在哪一步写入的，许圆想核对现实房间里哪些东西出现在了画面里。主角要沿着前半程亲手取到的证据，找回被留空的 05 号记录。

后半程复用 **5F 活动室与走廊、4F 连廊三处视图、3F 机房**。第二次熄灯改变熟悉地点的可交互层。最初用来取参考图的椅子、灯和门，最后变成核对「谁回来了」的依据。周日的自愿展示从活动室电脑准备，展示现场用字幕交代。

### 情节解答

去年林未设计过一段离队后重新归队的试玩流程。备份里的 05 号有手工登记，却缺了一次「归队确认」，原提交版因此漏掉了这一格的名字。异常预览每次走到这一步，都会把未确认的空位套到画面里最后一个独处的人身上。一起看时，四人同时看到预览里的队友离场，玩家被标为「缺席」。独自查看时，队友围过来触发预览刷新，玩家恢复「在线」，空位退回 05 号。

玩家最终恢复的是林未的**原工程署名**，保留她现实中的状态为「待确认」，并给本队四人各自确认归队。完成后连续播放两次都显示「本队四人已归队」，05 号保持「林未，待确认」。旧工程能复现现实房间的原因留作微恐怖余韵，林未的现实下落也由后续联络追查。

## 2. S5 复盘旧场景

24H 完结页在完整版增加「继续后 24H」入口，载入赛程周六 16:05 的活动室。唐澈关掉循环播放，保留只读副本。本队游戏仍在另一个本地工程里。第一次点电脑前，玩家先听袁祁说明接下来的目标。

> 袁祁「刚才人都在这儿。要查的是它为什么写你缺席。今晚过十一点半以前，我们先把那一格是怎么出来的弄明白。」

### P4 定位「缺席」写入点

| 前半程选择 | 玩家操作 | 可查依据 | 完成反馈 |
| --- | --- | --- | --- |
| 一起看 `ViewTogether` | 打开「四人的目击记录」，对照房间草图上的纸团位置和名单抄件上的 05 空格，从三张帧卡中选出相符的一张。 | 许圆画的纸团在插线板左侧。袁祁抄下的第五格只有编号 05。第一张卡的纸团在右边，第二张同时符合两项记录，第三张有一条主角「缺席」的记录占了 05 号空格。 | 得到「写入前的暂停帧」，显示三名画面角色开始离场，05 仍待确认。 |
| 独自查看 `ViewAlone` | 在电脑打开「离线预览日志」，用一张快照卡和两条状态日志排出事件先后，再点「回放这一段」。 | 快照卡描写三名画面角色先离场。两条日志按写入时间先后显示「主角缺席」和「队友靠近后主角恢复在线，05 显示缺席」。 | 得到「状态变化的时间段」，确认最后一条同时涉及两个槽位。 |

对错反馈指出哪一条实物或哪一个先后关系对不上，保留已经核对的条目。玩家可从备忘录重读证据。第一次完整核对后，系统把「当前玩家的临时标记」与「05 的原待确认项」显示为两行。查看尚未核实的归队规则时出现林未的旧测试说明「公共灯熄灭后，按归队表验一次」，指向第二晚的实地取证。

点击电脑旁的「等到熄灯」推进到 23:29。纸面路线由许圆随主角下楼辨认资料，玻璃路线由唐澈随行核对机房数据。袁祁与剩下的一名队友留在 5F 守门，通过手机和外出的两人联络。陪同通过短对白表现，四人的去向在出门前交代清楚。

## 3. S6 第二次熄灯

23:30，门玻璃外变暗，活动室灯和室内插座仍亮。玩家从 5F 走廊下到单数栋 4F 入口。前一晚的路线决定这次能优先使用的证据。玩家可按需要调应急灯或返回 5F 休息。

### P5 纸面路线 `RouteLight`

**必经路径**　5F 走廊 → 单数栋 4F 入口 → 连廊中段 → 偶数栋 4F 资料柜 → 原路回 5F。

1. 在单数栋入口开应急灯，查看导览旁边已露出的旧展位号。许圆用前一晚的纸面编号定位「归队测试」当初用的资料柜。
2. 偶数栋的柜子沿用前一晚的开锁状态。点柜门内侧翻起折页，再从背包把「分工表残页」用于折页。展开的是同一张表的另一半，原来的第五格只剩「05」，折页有同号的装订记号。
3. 对照后，点击折页上与 05 对应的「归队确认」栏。其余栏属于玩法说明和展位巡查，点击会提示所属标题。正确栏写着「原作者留在原格。现队到齐后各记各的，空格可保留为待确认」。
4. 许圆抄下这一行，备忘录登记「纸质归队规则」。玩家可以直接回 5F。相同折页可重复看。

> 许圆「我把纸掀起来了。这里写的是‘待确认’。第五格下面原来还有位置，能把人的名字留住。」

### P5 玻璃路线 `RouteDark`

**必经路径**　5F 走廊 → 单数栋 4F 入口 → 连廊中段 → 返回单数栋楼梯 → 3F 机房 → 5F。

1. 在灯灭时查看中段玻璃。倒影显示机房备份里的测试片段标记「第二次门响，选归队页」。这次交互将标记记进备忘录，首次最多扣 15 SAN。应急灯可在取完标记后打开。
2. 回单数栋从熟悉的楼梯下到 3F。在靠窗第 3 台电脑使用旧工程 U 盘，进入只读测试时间轴。三张音效事件卡同时显示次序、字幕和关联页面，依次为「门响／离队」「门响／归队」「椅脚声／结算」。玩家根据玻璃上的提示选择第二张。点错会显示该卡所属页面，时间轴保持开启。
3. 打开归队页，核对备份中的「归队人数」与「05 待确认」两栏。归队人数单独填写，05 可以保留原名和待确认状态。备忘录登记「备份中的归队规则」。玩家带着原 U 盘回 5F。

> 唐澈「这是她给试玩录的触发点。第二次门响之后，可以填回来的有几个人。05 那一栏单独留着。」

两条路线各自提供完成 S7 所需的规则。一条把旧纸和实物对齐，另一条靠残影定位、再用真实的本地记录核实。灯光反复切换仍沿用原调查路线。以前读过玻璃留言的玩家在看到这次倒影时会认出字迹。带着旧版留暗存档来的玩家也可直接调查这次倒影。

## 4. S7 确认归队

回到活动室，走廊仍黑。桌上灯亮着，白框里的第五把椅子空着。玩家把 4F 或 3F 取得的规则带到电脑，唐澈打开待核对的名单副本。这个环节完成后，队伍才愿意再次让场景走到结算。

### P6 恢复 05 号并复查

1. **恢复原署名。** 从纪念盒热点调出工牌记录，在电脑名单上点中 05，再选择「林未」与「待确认」。工牌正面给出名字和编号，归队规则给出状态选法。选中主角或将林未设为「已归队」，界面会指出与工牌或现有证据的差异。原始文件仍保存在 U 盘。
2. **核实本队四人。** 主角点击「我已归队」，让三名队友分别应答。应答完成后电脑里的「本队」行显示 4/4，旧名单里的 05 单列。「我已归队」在记录了纸质或备份规则后出现。
3. **按前半程的证据复查。** 一起看路线使用「与队友对照」，玩家在暂停帧上点 05 和主角两行，让袁祁读名单、许圆核对那把空椅。独自看路线使用「回放日志片段」，玩家把游标移到 P4 查到的第二次状态变化，逐帧检查原来两行同时改变的地方。操作完播放到结算，确认主角显示「已归队」，林未显示「待确认」。
4. **验证第二遍。** 玩家点电脑重播一次。两行状态在同一位置保持稳定，传来一声椅脚轻响。现实里的第五张椅子仍空着。袁祁把确认页存进备忘录，并让玩家点击休息，进入周日上午。

> 我「我回来了。那一格写林未，状态先记‘待确认’。她的名字得留在自己的位置上。」

### 中途反馈与失败保护

| 条件 | 处理 |
| --- | --- |
| 选错帧、事件或名单 | 保留已核对的项目。提示对应文档、事件或栏位，可以立即重试。 |
| 约 45 秒无进展 | 队友提示眼下该比对的物件或字段。详细线索可在备忘录翻看。 |
| 夜间照明与 SAN | 沿用既有危险区规则。暗处每 20 秒扣 1 SAN。4F 应急灯亮时暂停该区被动消耗，查看对白和文档时暂停计时。 |
| SAN 为 0 或生命耗尽 | 凝视及关键交互仍有效。生命耗尽回 5F 安全屋，恢复 SAN 60、生命 3，保留路线、规则和谜题进度。可休息回满。 |
| 界面可读性 | 帧卡的纸团位置、事件的门响次序和名单状态都带文字。残影标明来源，路标和出入口保留常规显示。 |

## 5. S8 封包与结局

周日 10:00，活动室恢复白天状态。四人把自己的 GameJam 作品做完。袁祁拿出两份可用的材料，一个是署名更正页，另一个是协会内部存档。玩家在 16:00 前从电脑上选择「带上更正页」或「封存原始材料」。菜单预先展示接下来的操作和资料去向。

| 最后选择 | 具体操作 | 结尾 |
| --- | --- | --- |
| 带上更正页 | 在电脑选中已核对的姓名与来源，将「旧工程署名更正」附在本队自愿展示的说明页，再点击「预览说明」并确认。说明页写明林未是旧工程的 05 号作者，原始证词与备份由协会私下保管。 | 字幕「周日 16:00」。本队封包，屏幕上依次显示自制作品名单和单独的旧工程更正页。许圆从电脑旁退开，让四个人都能看见林未的全名。 |
| 封存原始材料 | 从背包使用旧 U 盘生成留存副本，在纪念盒热点把副本与纸面记录归在同一份档案里，再回电脑封包本队作品。袁祁留存档案编号，以便联系去年队员核对。 | 字幕「周日 16:00」。本队作品完成，镜头停在关上的纪念盒。盒内档案索引显示「05 林未 · 原工程署名 · 待确认」。 |

两种结尾都保有修正后的旧署名和今夜归队的记录。作品展示由队伍自行决定。结尾复用活动室固定视图、电脑上的两张小面板和黑底字幕。

## 7. 接续、存档和验收

完整版接收 S4 已完成的章节状态，沿用 `RouteLight / RouteDark`、`ViewTogether / ViewAlone`、SAN、生命、物品和纪念盒状态。目击记录或离线日志按 `viewChoice` 从现有结尾还原。为旧版已完成结尾的存档重建对应的复盘入口。后半程用现有章节存档和槽位结构承载，进度主要包括 P4 复盘结果、P5 路线规则、P6 名单与复查状态、最后的封包选择。

检查点设在接续 S4 后、P4 完成后、P5 取证后、P6 完成后及最终选择确认后。新增可重复的查看动作采用一次性扣值和标记，读档恢复当前阶段、所在视图和已完成步骤。恢复于结局操作中途时，直接显示剩余操作。

1. 从两种 24H 结尾分别进入 S5，能拿到对应的帧卡或日志，复盘步骤与此前证据匹配。
2. 开灯路线只需到偶数栋资料柜，留暗路线只需到 3F 机房核对备份。两条路线都能独立生成归队规则并回到 5F。
3. 每种 S2 路线与每种 S4 查看方式都能通往两种封包结尾，共八条完整组合。中途读档可继续，零 SAN 可通过留暗路线。
4. 同一地点二次到访时可以认出桌椅、门、海报和原来的箭头。新增提示仅在对应操作可用时出现。
5. 48H 结尾能回答 05 号原属于谁、主角为何被标成缺席、现队如何确认归队，并明确玩家最后给署名更正选择了什么去向。
