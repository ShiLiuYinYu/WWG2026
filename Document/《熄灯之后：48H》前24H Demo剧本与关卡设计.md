# 《熄灯之后：48H》前 24H Demo 剧本与关卡设计

> 版本：v4。GameJam 从周五 16:00 开始，Demo 覆盖至次日的第 24 小时节点，目标游玩时长约 25–35 分钟。主题为 **「选择」**。

## 1. 核心体验与范围

玩家是游戏开发协会四人队的关卡策划，和队友在熟悉的单数栋五楼活动室参加 48H GameJam。协会有多支参赛队，其他队分在创客教室或线上协作。玩家先为本队夜景取材，再从有异常的旧照片和椅垫下的工牌追查一位去年失联的成员。走廊在周五 23:30 按规定熄灯，室内设备继续供电。四楼可选纸面或玻璃取证，三楼根据纸质线索恢复旧备份。第 24 小时，两种预览方式需要不同的操作，各自留下可供之后调查的记录。

第一版只做 **单数栋 5F 活动室及走廊、4F 连廊两端、单数栋 3F 机房**。其余学院通过楼层牌、天井俯视、门牌和广播建立空间感，暂不制作可探索房间。5F 活动室是安全屋；其余区域在熄灯后是危险区。白天让玩家点击查看活动室、走廊、楼梯口、连廊入口，夜里用同一批画面改变照明与可交互物。每屏是固定 2D 场景，点击热点调查，点箭头切屏，选背包道具后再点场景使用；无自由行走、战斗或追逐。

**活动边界：**GameJam 只提供开题主题与最终展示机会，不设参赛者监控、夜间签到、24H 强制汇报或统一上传。故事里的照片、备忘和电脑工程都是社团成员自己留下的资料。周六 16:00 是队伍自行约定的“做出第一版可玩内容”节点，不是主办方检查。

## 2. 人物与叙事规则

| 人物 | 戏剧作用 | 口吻 |
| --- | --- | --- |
| 玩家（不预设姓名） | 关卡策划，为夜景取材；照片异变后查工牌主人，把目击和实物对上 | 熟悉日常路线，遇到异常先找能核对的细节 |

玩家必须能区分三层信息：**当下的真实场景**（四位队员、正常门牌）、**社团自留资料**（照片、便签、旧工程）和 **低 SAN 残影**（旧字、第五个人的轮廓）。残影可以给真线索，但不直接告诉玩家整件事的原因。队友不会在玩家视野外突然消失；本 Demo 不用“全是幻觉”推翻玩家的调查成果。

## 3. 分章剧本与玩家操作

游戏中的逐行对白以 `Assets/Yarn/Chapters/` 为准，长文档由 `DialogueDocuments` 提供。

### S0 · 熟悉的活动室，周五 15:40–23:30

- **楼外。** 主角本来就会走单数栋五楼的路线。门口展板可选读，用来核对周五 23:30 的熄灯规定，直接进门也能推进。
- **集合与开题。** 协会有好几队参赛，两队在创客教室，做音游的一队在宿舍连麦。袁祁登记了四人常用的活动室，唐澈能沿用协会测试机和既有环境。第五把椅子平时开例会也空着，椅背留有去年的编号。
- **白天取景。** 16:00 公布主题「选择」。许圆提议用熟悉的实验楼做有限场景，主角负责拍参考图。活动室拍第五把椅子、白色地胶框及柜顶旧盒，5F 走廊拍常亮的出口牌并查看定时箱，4F 连廊读去年导览稿并观察应急开关。其余三人搭测试框架和美术草稿。
- **当晚开发。** 回活动室汇报后，时间推进到 18:30、21:15、23:29。队伍约定次日 16:00 自己跑第一版。23:30 门外走廊灯灭，室内设备继续工作，旧纸盒掉下，滑出一张背面朝上的照片。

### S1 · 照片与工牌，周五 23:30–周六 00:10

- **摆回夜景（P1）。** 许圆的夜景草稿太暗，想参考旧照片里桌灯照出热点的方式。主角拉窗帘、开桌灯、挪第五把椅子到白框，顺序不限。三处匹配后，照片里浮出人影，主角受到一次 SAN 冲击。
- **核实人名。** 袁祁注意到刚挪动的椅垫下夹着工牌。正面是林未和 05，背面写「玻璃两边，各存一半。4F」。许圆记得去年的合照署名里没有这个名字。主角先核对手里的实物，再决定去连廊查取件线索。
- **分工。** 袁祁守活动室和通话，也联系去年的带队学长。许圆从窗边留意连廊。唐澈查社团旧群文件和机位。主角熟悉两栋间的路径，沿这条路下楼。活动室门玻璃的低 SAN 残影可额外调查，主线由工牌推进。

### S2 · 四楼取证，周六 00:10–01:00

1. 单数栋入口的电话先交代灯光的影响。开灯便于看墙面和揭贴纸，留暗便于看玻璃。中段首次点击右侧玻璃时，灯光决定调查路线。入口开关可继续使用，首次选择一直保留。
2. **开灯 `RouteLight`。** 应急灯亮时分别点击两栋远端的海报，沿翘边揭开贴纸，取得 7 和 1。两张近端海报直接读取 2 和 4。
3. **留暗 `RouteDark`。** 第一次点击看到两张远端海报的倒影。灯灭时再次点击玻璃，凝视一次获得远端 7、1 和「别只看照片，看看他们留下了什么」的留言，扣除最多 40 点 SAN。近端 2 和 4 仍要到两端核对。拿到倒影里的数字后可以回入口开灯。
4. **资料柜。** 旧柜曾用于协会的解谜试玩，柜门便签指向四张展位海报。按导览将四个编号排好为 `2741`。记齐四个数字后可以输入，打开抽屉取得借用便签和分工表残页。袁祁在电话里确认学长只记得林未熄灯后下楼，唐澈确认常用的校园卡仍能刷进机房。借用便签指定单数栋三楼靠窗第三台机器，玩家可先回五楼休息。

### S3 · 本地备份，周六 01:00–02:00

- **机房取证（P3）。** 主角刷卡进熟悉的机房，按便签找靠窗第三台机器。可读桌上的草图与次日留言。唐澈在电话里解释暂存区与归档工具。玩家核对林未、单数栋 3F 靠窗第 3 台和 23:30 三项索引，恢复 `AfterLightsOut_Backup`。
- **录音与备份。** 林未发现自己的署名从工程里消失，决定把工牌留在椅垫下，把自己的备份留在机房。她亲手拍的照片里，本来空着的椅子坐着她自己。录音以门把手轻响截断。袁祁希望留存她的原始署名，唐澈让主角把整个备份拷入 U 盘，到五楼再做离线检查。拷贝时发现打不开的 `周六_16:00.scene`。

### S4 · 选择怎么查旧工程，周六 02:00–16:05

- **夜间归档。** 回五楼后，袁祁整理纸面记录、继续联系学长。唐澈把旧备份与本队工程隔开，准备离线预览。把工牌收入协会纪念盒，SAN 上限升至 120；在安全屋休息后天亮，SAN 和生命恢复。
- **白天复盘。** 休息结束后自动开始复盘。袁祁确认资料中的名单差异，许圆按实际取得的线索记下纸面号码或玻璃残影。随后唐澈确认第一版 Demo 跑通，旧场景在 16:00 解锁。查看方式的选项随对白打开。玩家可以暂缓，再点电脑即可回来选择。
- **一起看 `ViewTogether`。** 唐澈停在第一帧，随后自动播放袁祁核对屏幕名册和许圆核对房间实物的对白。两段对白结束后，玩家点电脑继续。四人共同目睹主角被标成「缺席」，留下四人的目击记录。
- **独自查看 `ViewAlone`。** 另外三人退到长桌另一头，选择时一次性扣 10 点 SAN。玩家从背包选中装有旧工程的 U 盘，点击「使用」载入离线快照，再点电脑播放。玩家先看见自己被标为「缺席」；队友围过来后状态变回「在线」，「缺席」转到 05 号林未。留下记录两次状态变化的本地日志。
- **结尾。** 已读到玻璃留言的流程会闪回那句话。通用悬念是旧工程为什么开始改写主角的状态。两个分支都显示「24:00:00 / 前 24H Demo 完结」，并标明这一局留下的证据。

## 4. 三个谜题的完整规格

### P1 旧照片对位（教学谜题，5F 活动室）

**目标：**重现旧照片里 23:30 的活动室布置，查看照片为什么发生变化。

**可见线索：**背包中的旧照片可随时放大查看；窗帘、桌灯、椅子在现实场景中的位置都清楚可见。地上白色地胶框在白天已经出现，避免夜里凭空冒出来。

**操作与唯一解：**拉上窗帘；打开桌灯；把储物柜旁的第五张椅子拖到白色地胶框内。三项全部匹配后自动显出照片的异常，不要求像素级摆放。玩家可以任意顺序操作，错误操作可直接撤销。查看照片时可显示「环境匹配 1/3」等状态。

**反馈与奖励：**每匹配一项，照片上的对应部分略微显影；完成时第五张椅子上出现人形轮廓，现实椅垫下出现旧工牌，开放 4F 目标。第一次盯住异常照片造成 SAN -25。工牌是剧情关键物，不可丢弃。

**提示梯度：**30 秒无进展，许圆说「照片里的窗帘是关着的」；60 秒无进展，高亮照片中的桌灯和地胶框。提示不代替操作。

### P2 连廊双栋四位数（空间与低 SAN 谜题，4F）

**目标：**打开旧设备柜，找到林未去 3F 的借用单。

**布局与线索：**4F 连廊两端各通一栋楼。导览练习稿清楚写「先单数栋、后偶数栋；从连廊口向外走」。单数栋有近、远两张海报，数字分别是 **2、7**；偶数栋有近、远两张，数字分别是 **4、1**。海报用不同位置和图案区分，避免玩家只靠颜色识别。设备柜有四位输入框。入口电话对白提及应急灯开关的位置，以及玻璃上隐约可见的痕迹。

**操作与唯一解。** 首次点击中段右侧玻璃按当时的照明确定路线。两张近端海报都要实地读。开灯路线保持灯亮，分别揭开两张远端贴纸；留暗路线灯灭时再次点中段玻璃，凝视一次读取两张远端的倒影和额外留言。累计记录四个展位号后，输入 **2741**。照明可随时回入口切换，已选路线和读数在休息或读档后保留。凝视最多扣 40 点 SAN；SAN 为 0 时也能取得必需的数字。

**反馈与奖励。** 凝视结果标为残影。数字记齐前，资料柜提示当前路线的取证地点；记齐后开放密码盘。锁面上方显示四位输入，下方是 1–9 的九宫格数字键。「删除」退一位，「确认」提交四位密码，「返回」关闭锁面。错误时保留输入，正确时打开设备柜，抽屉提供借用便签和分工表残页。

**提示梯度。** 45 秒未集齐远端编号，按路线提示贴纸或中段倒影。90 秒后提示查看任务记录。未发现的数字显示问号。生命耗尽时回单数栋入口，选择与证据保留。

### P3 三项证据恢复旧工程（推理谜题，单数栋 3F）

**目标：**从损坏的本地备份中恢复林未留下的旧游戏工程。

**可见线索及对应关系：**

| 恢复工具字段 | 可查证据 | 正确输入 |
| --- | --- | --- |
| 作者 | P1 取得的旧工牌正面 | 林未 |
| 保存机位 | P2 设备柜里的机房借用便签 | 单数栋 3F，靠窗第 3 台 |
| 保存时间 | 5F 旧照片背面及借用便签 | 23:30 |

**操作与唯一解：**三个字段用选项按钮选择，不要求键盘输入中文；每项放 3 个候选。玩家可在恢复工具上直接打开背包查看工牌、借用便签和旧照片。三项全部正确才恢复工程与语音备忘。错误字段会标红并提示「与纸质记录不一致」，不扣 SAN、不清空正确项。

**反馈与奖励：**恢复旧工程、获得 U 盘拷贝、开放返回 5F 的主目标。第一次听语音备忘时有固定 SAN -15 的冲击；语音可跳过重复播放，完整文字可在任务记录中重看。

**提示梯度：**60 秒无进展，唐澈说「旧工程按作者、机位和时间分过文件夹」；120 秒后逐一标亮对应背包物件。

## 5. SAN、生命、养成与失败保护

这些数值是 Demo 的初始调参，目标是让玩家感到视野变化，同时不因探索过慢而卡死。屏幕右上沿用现有 UI 草图显示 SAN 与生命；对话时保持可见。场景切换走楼梯/连廊热点，不做整栋开放漫游。

| 规则 | Demo 参数与作用 |
| --- | --- |
| 初始值 | SAN 100/100，生命 3/3 |
| 危险区 | 夜间 5F 走廊、未开应急灯的 4F 连廊、3F 机房每 20 秒 SAN -1；4F 开灯后停止该区的被动消耗。只在玩家可操作时计时，读文字/听语音暂停 |
| 主动凝视 | 留暗路线再次点击灯灭时的连廊中段玻璃，读取两张远端海报倒影和留言，最多扣 40 点 SAN，重复查看已读倒影不扣 |
| 剧情冲击 | P1 -25、P3 -15、S4 独自打开 -10；数值动画明确提示原因 |
| SAN 为 0 | 视野扭曲且每 15 秒生命 -1；生命为 0 时回最近安全点，恢复 SAN 60、生命 3，谜题进度和已收集物不回滚 |
| 安全屋 | 夜间 5F 活动室可坐下休息，SAN 回满、生命回满；休息无需消耗品 |
| 养成 | P3 后把林未工牌放入 5F 纪念盒，SAN 上限 100→120，体现“解谜获得物品以供养成”；仅这一项，后 24H 可扩展 |

低 SAN 是**另一层可读线索**，不是让玩家随机看到错误数字；P2 的数字既能靠开灯揭贴纸取得，也能靠主动凝视取得。安全屋回满后仍能再次凝视。P1、P2、P3 的关键物都是任务物品，不允许丢弃或消耗。随时可从暂停菜单读取最近场景检查点；存档包含时间段、SAN/生命、谜题状态、背包、两个选择标记和已触发对话。

## 6. 场景、UI 与最小制作清单

### 2D 点击交互与后续场景素材规格

每个地点用一张固定视角的现实风格背景，正对可调查区域；左键点击热点调查或切换地点。背包道具可拖到场景热点使用，右键查看物件详情。可交互处在鼠标悬停时只给轻微描边或光标变化，不在背景上常驻大按钮。P1 的椅子拖放只需吸附到地胶框，不做物理模拟。低 SAN 变化通过少量局部覆盖图、玻璃反射、音效和 UI 实现，避免整屏强烈扭曲。

后续生成场景图时，先固定同一套空间结构和视角，再做日/夜、灯开/关版本。建议以 16:9 横屏为基准，保证对话框和背包不会遮挡关键线索。文字、谜题数字、工牌、照片、人物和可移动椅子尽量做成独立图层或 UI 元素，不烘焙在背景里；这样分支与解谜只需切换局部素材。

| 固定场景画面 | 必须留出的可交互区域 |
| --- | --- |
| 实验楼外景（白天） | 入楼入口、单/偶数栋、天井与连廊轮廓、楼层导览牌 |
| 5F 活动室（白天/夜间） | 窗帘、桌灯、靠窗椅子与地胶框、储物柜、电脑、纪念盒、安全屋座位 |
| 5F 走廊与楼梯口（白天/夜间） | 灯、楼层牌、4F/3F 切屏箭头、活动室返回入口 |
| 4F 单数栋与连廊（暗/应急灯亮） | 导览练习稿、两张海报、应急灯开关、通往偶数栋的箭头 |
| 4F 偶数栋（暗/应急灯亮） | 两张海报、旧资料柜、返回单数栋的箭头 |
| 单数栋 3F 机房（夜间） | 靠窗第三台电脑、手绘草图、返回楼梯的箭头 |

美术方向是普通高校实验楼：真实的桌椅、磨损的地胶、冷白荧光灯和夜间天井。恐怖感来自同一画面中不合逻辑的小变化，不靠血迹、怪物立绘、夸张鬼脸或追逐镜头。旧照片与结尾的旧工程场景要严格复用活动室的门窗位置和透视关系，玩家才能一眼发现第五张椅子的变化。

**建议 48H 实际开发顺序：**先搭 5F→4F→3F→5F 的点击切屏和热点，再做 P1/P2/P3 的状态与道具，以及两个选择标记和两种结尾文案；随后接入 SAN 与存档，最后补灯光、声音和演出。若工期吃紧，保留两个决定、三个谜题和 24H 悬念，缩短楼外探索、用文字加音效代替完整语音、把 NPC 对话改成字幕。不要删 P2 的双栋读数规则，否则建筑结构失去玩法意义。

### Demo 完成判定

1. 新玩家不看攻略，能从开题走到「剩余 24:00:00」结尾，预计 25–35 分钟。
2. 三道谜题都有场景内可查的完整线索、明确的正确解、错误反馈与提示，不依赖随机猜码。
3. 玩家在 SAN 清零或生命耗尽后仍可继续，所有关键物与谜题进度不会丢失。
4. 白天的五楼与夜间同一地点可辨认；23:30 只熄公共照明，活动室和机房电脑继续通电。
5. 结尾明确回答“林未是谁、去年留下了什么可确认的证据”，同时留下“旧工程为何把玩家标为缺席”的后 24H 问题。
6. 两条 4F 路线都能各自完成取证并进入 P3。两种终章查看方式分别完成目击核对和 U 盘预览，留下不同的证据。载入存档后可继续各自未完成的操作。
