# 《熄灯之后：48H》前 24H Demo 剧本与关卡设计

> 版本：可制作方案 v3。故事中的 GameJam 从周五 16:00 开始；本 Demo 覆盖到周六 16:00（赛程第 24 小时），实际游玩约 25–35 分钟。本届开题主题固定为 **「选择」**。这是现实风格、2D、微恐怖的场景点击解谜游戏。以下人物、旧事件与谜题是基于现有设定新增的创作内容，并非原文已有事实。

## 1. 核心体验与范围

玩家是四人队的关卡策划，来到实验楼五楼游戏开发协会活动室参加 48H GameJam。本届开题主题是 **「选择」**：队伍要围绕它做游戏，玩家也必须在调查中作出有后果的选择。走廊在周五 23:30 按规定熄灯，室内设备仍有电。玩家在社团活动室找到去年队伍自留的照片；照片上的第五张椅子逐渐出现一个人影。玩家借助正常视野和低 SAN 时出现的残影，从五楼追到四楼连廊、三楼机房，找到照片主人的旧游戏工程，再返回安全屋。第 24 小时，玩家选择是否让队友一起打开旧工程，看到的内容将发生变化。

第一版只做 **单数栋 5F 活动室及走廊、4F 连廊两端、单数栋 3F 机房**。其余学院通过楼层牌、天井俯视、门牌和广播建立空间感，暂不制作可探索房间。5F 活动室是安全屋；其余区域在熄灯后是危险区。白天让玩家点击查看活动室、走廊、楼梯口、连廊入口，夜里用同一批画面改变照明与可交互物。每屏是固定 2D 场景，点击热点调查，点箭头切屏，选背包道具后再点场景使用；无自由行走、战斗或追逐。

**活动边界：**GameJam 只提供开题主题与最终展示机会，不设参赛者监控、夜间签到、24H 强制汇报或统一上传。故事里的照片、备忘和电脑工程都是社团成员自己留下的资料。周六 16:00 是队伍自行约定的“做出第一版可玩内容”节点，不是主办方检查。

## 2. 人物与叙事规则

| 人物 | 戏剧作用 | 口吻 |
| --- | --- | --- |
| 玩家（不预设姓名） | 队里的关卡策划；负责查清异常 | 第一人称内心旁白，短句，不替玩家下结论 |
| 袁祁 | 队长，现实锚点；夜里留在 5F 安全屋 | 急于按时交作品，逐渐担心玩家 |
| 唐澈 | 程序，提供设备与机房线索 | 用技术解释怪事，但不否认眼前事实 |
| 许圆 | 美术，发现画面里的细节 | 对“第五张椅子”最先不安 |
| 林未 | 去年活动的失踪参赛者，通过工牌、照片、个人语音备忘出现 | 不安排实体追逐；留下的消息像在提醒下一届的人 |

玩家必须能区分三层信息：**当下的真实场景**（四位队员、正常门牌）、**社团自留资料**（照片、便签、旧工程）和 **低 SAN 残影**（旧字、第五个人的轮廓）。残影可以给真线索，但不直接告诉玩家整件事的原因。队友不会在玩家视野外突然消失；本 Demo 不用“全是幻觉”推翻玩家的调查成果。

## 3. 剧本：按场景可直接放入游戏的文本

### S0 楼外与开题，周五 15:40–16:10

镜头从实验楼外开始。玩家看到单数栋、偶数栋及中间天井和连廊。门口展板写明：1F 电气与电子工程、2F 机器人、3F 计算机工程、4F 外国语、5F 数智设计；工作日 23:00 熄灯，周五、周六 23:30 熄灯，**熄的是公共区域照明，室内插座不断电**。这些信息之后必须在地图和物件上仍可查阅。

- 玩家旁白：「48 个小时，做出一个能玩的游戏。我们连题目都还不知道。」
- 袁祁（活动室）：「人齐了？四个。靠窗那把椅子先别搬，等会儿方便摊材料。」
- 许圆：「五把椅子，四个人。挺像恐怖游戏的开场。」
- 唐澈：「别给策划加需求。」
- 16:00 开题直播主持：「本届 48H GameJam 的主题是——**选择**。后天下午四点前做出可玩的作品，之后大家一起展示。」
- 袁祁：「选择？那得让玩家真的为自己的决定负责。」
- 许圆：「先别写分支树，咱们只有 48 小时。」
- 开题直播结束后，队伍各自讨论题目。玩家点击桌边的第五张椅子，听到许圆说：「我们四个人，留一把椅子做什么？」此时只是普通环境细节，无异常画面或监控镜头。

白天自由查看三个记忆点：五楼活动室靠窗的椅子、走廊的安全指示牌、四楼连廊入口贴的“双栋导览图”。与袁祁对话后时钟快进。用字幕「23:29 / 公共照明熄灭倒计时」回到活动室；走廊灯逐盏熄灭，室内用于做游戏的电脑仍亮。

## 4. 三个谜题的完整规格

### P1 旧照片对位（教学谜题，5F 活动室）

**目标：**重现旧照片里 23:30 的活动室布置，查看照片为什么发生变化。

**可见线索：**背包中的旧照片可随时放大查看；窗帘、桌灯、椅子在现实场景中的位置都清楚可见。地上白色地胶框在白天已经出现，避免夜里凭空冒出来。

**操作与唯一解：**拉上窗帘；打开桌灯；把储物柜旁的第五张椅子拖到白色地胶框内。三项全部匹配后自动显出照片的异常，不要求像素级摆放。玩家可以任意顺序操作，错误操作可直接撤销。查看照片时可显示「环境匹配 1/3」等状态。

**反馈与奖励：**每匹配一项，照片上的对应部分略微显影；完成时第五张椅子上出现人形轮廓，现实椅垫下出现旧工牌，开放 4F 目标。第一次盯住异常照片造成 SAN -25。工牌是剧情关键物，不可丢弃。

**提示梯度：**30 秒无进展，许圆说「照片里的窗帘是关着的」；60 秒无进展，高亮照片中的桌灯和地胶框。提示不代替操作。

### P2 连廊双栋四位数（空间与低 SAN 谜题，4F）

**目标：**打开旧设备柜，找到林未去 3F 的借用单。

**布局与线索：**4F 连廊两端各通一栋楼。导览练习稿清楚写「先单数栋、后偶数栋；从连廊口向外走」。单数栋有近、远两张海报，数字分别是 **2、7**；偶数栋有近、远两张，数字分别是 **4、1**。海报用不同位置和图案区分，避免玩家只靠颜色识别。设备柜有四位输入框。入口处的开关明确标示「应急照明」，交互前告知玩家开灯会盖住残影，保持黑暗会继续消耗 SAN。

**操作与唯一解：**进入 4F 时先记录 `RouteLight` 或 `RouteDark`，一经触发不能改写。若先开应急灯，玩家可撕开两张远端海报的新贴纸，直接读出数字，不付出额外 SAN，但看不见玻璃留言。若选择保持黑暗，玩家面对远端海报各「凝视」一次，SAN 每次 -20，局部显示旧数字约 8 秒；SAN ≤60 时旧数字持续可见，并能在连廊中央读到额外留言。得到留言后可以再开灯返程，路线标记仍是 `RouteDark`。两条路线都按规则输入 **2741**，拿到同一张借用单。回 5F 安全屋恢复 SAN 不会清空已读数字；柜门无限次输入，无惩罚锁死。

**反馈与奖励：**每次凝视有玻璃反射和轻微失真，而非强闪屏；正确时设备柜开启，拿到借用单。错误时屏幕提示「顺序不符」，四位输入保留，方便改正。

**提示梯度：**45 秒未读到远端数字，开灯路线提示「贴纸可以揭开」，留暗路线提示「新贴纸下面像还有一层旧字」；90 秒后任务记录直接列出已发现数字及相对位置（单近 2、单远 ?、偶近 4、偶远 ?）。在连廊最低 SAN/生命值状态下，允许玩家一键退回最近楼梯安全点，不让谜题变成耐力消耗。

| SAN 为 0 | 视野扭曲且每 15 秒生命 -1；生命为 0 时回最近安全点，恢复 SAN 60、生命 3，谜题进度和已收集物不回滚 |
| 安全屋 | 夜间 5F 活动室可坐下休息，SAN 回满、生命回满；休息无需消耗品 |
| 养成 | P3 后把林未工牌放入 5F 纪念盒，SAN 上限 100→120，体现“解谜获得物品以供养成”；仅这一项，后 24H 可扩展 |

低 SAN 是**另一层可读线索**，不是让玩家随机看到错误数字；P2 的数字既能靠开灯揭贴纸取得，也能靠主动凝视取得。安全屋回满后仍能再次凝视。P1、P2、P3 的关键物都是任务物品，不允许丢弃或消耗。随时可从暂停菜单读取最近场景检查点；存档包含时间段、SAN/生命、谜题状态、背包、两个选择标记和已触发对话。

### 2D 点击交互与后续场景素材规格

每个地点用一张固定视角的现实风格背景，正对可调查区域；左键点击热点调查或切换地点。背包道具可拖到场景热点使用，右键查看物件详情。可交互处在鼠标悬停时只给轻微描边或光标变化，不在背景上常驻大按钮。P1 的椅子拖放只需吸附到地胶框，不做物理模拟。低 SAN 变化通过少量局部覆盖图、玻璃反射、音效和 UI 实现，避免整屏强烈扭曲。

后续生成场景图时，先固定同一套空间结构和视角，再做日/夜、灯开/关版本。建议以 16:9 横屏为基准，保证对话框和背包不会遮挡关键线索。文字、谜题数字、工牌、照片、人物和可移动椅子尽量做成独立图层或 UI 元素，不烘焙在背景里；这样分支与解谜只需切换局部素材。

| 固定场景画面 | 必须留出的可交互区域 |
| --- | --- |
| 实验楼外景（白天） | 入楼入口、单/偶数栋、天井与连廊轮廓、楼层导览牌 |
| 5F 活动室（白天/夜间） | 窗帘、桌灯、靠窗椅子与地胶框、储物柜、电脑、纪念盒、安全屋座位 |
| 5F 走廊与楼梯口（白天/夜间） | 灯、楼层牌、4F/3F 切屏箭头、活动室返回入口 |
| 4F 单数栋与连廊（暗/应急灯亮） | 导览练习稿、两张海报、应急灯开关、通往偶数栋的箭头 |
| 4F 偶数栋（暗/应急灯亮） | 两张海报、旧资料柜、返回单数栋的箭头 |
| 单数栋 3F 机房（夜间） | 靠窗第三台电脑、手绘草图、返回楼梯的箭头 |

美术方向是普通高校实验楼：真实的桌椅、磨损的地胶、冷白荧光灯和夜间天井。恐怖感来自同一画面中不合逻辑的小变化，不靠血迹、怪物立绘、夸张鬼脸或追逐镜头。旧照片与结尾的旧工程场景要严格复用活动室的门窗位置和透视关系，玩家才能一眼发现第五张椅子的变化。

**建议 48H 实际开发顺序：**先搭 5F→4F→3F→5F 的点击切屏和热点，再做 P1/P2/P3 的状态与道具，以及两个选择标记和两种结尾文案；随后接入 SAN 与存档，最后补灯光、声音和演出。若工期吃紧，保留两个决定、三个谜题和 24H 悬念，缩短楼外探索、用文字加音效代替完整语音、把 NPC 对话改成字幕。不要删 P2 的双栋读数规则，否则建筑结构失去玩法意义。

### Demo 完成判定

1. 新玩家不看攻略，能从开题走到「剩余 24:00:00」结尾，预计 25–35 分钟。
2. 三道谜题都有场景内可查的完整线索、明确的正确解、错误反馈与提示，不依赖随机猜码。
3. 玩家在 SAN 清零或生命耗尽后仍可继续，所有关键物与谜题进度不会丢失。
4. 白天的五楼与夜间同一地点可辨认；23:30 只熄公共照明，活动室和机房电脑继续通电。
5. 结尾明确回答“林未是谁、去年留下了什么可确认的证据”，同时留下“旧工程为何把玩家标为缺席”的后 24H 问题。
6. 两条 4F 路线都能获得四个数字并完成 P3；两种查看旧工程的选择都可通关，且队友是否目睹异常确实不同。读取存档不会把已选路线或结局改回默认值。
