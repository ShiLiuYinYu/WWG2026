# 决策记录

## 2026-11-16 · temp1 界面与资源约定

| 决策 | 原因与实现位置 |
| --- | --- |
| 所有新建格子和面板由 `WWG/UI/Apply temp1 Layout` 在编辑器中写入已有预制体或场景；再次执行只更新样式或已有对象 | 保留人工微调的位置；不在运行时反复生成布局。迁移脚本：`Assets/Editor/Temp1UiMigration.cs`。 |
| S0/S1 共用右下角背包预制体，S2 现阶段沿用独立场景 UI，但统一为相同的 5×5 交互布局 | 当前 `GameplayOverlay` 尚未接管 S2；避免为了外观改动提前实施架构重构阶段 4–5。 |
| 无物品图标时格子显示物品名称；背包的 25 个格位按固定顺序保存为空格与已获得物品 | 现有章节的关键物品数量少，方便之后逐格替换图标且不改变尺寸。 |
| S1 的“使用”选择道具并由指针带到场景热点；S2 当前四件物品只承担线索查看 | S2 当前关卡未实现道具与热点结合的操作，不新增虚假的消耗品或谜题行为。 |
| UI 框统一使用 `选择框.png`，按钮统一使用 `选项按钮.png`，直接拉伸 | 满足现有素材复用和人工调整位置的要求。场景热点的不可见点击区域不应用可见按钮皮肤。 |
| 对话框高度设在预制体底部约四分之一，人影放在框上方；具体位置和文本边距保留为可编辑参数 | 方便后续在 Unity 中微调；对话脚本不写死纵向坐标。 |
| 角色图复制到项目内并由对白立绘 Image 以深色着色呈现 | 保留原素材透明轮廓，统一黑色人影效果；电话说话人仍显示「（电话）」后缀。 |
| 备忘录内容维护清单放在 `Document/Requirement/备忘录内容.md`，动态状态仍由章节控制器提供 | 保留资料、现实调查、残影的区分，并标明每条文案的实际代码来源。 |
| “锈湖风格”先落实在 UI 的纸张、深色人影、低饱和色块与线索层级；场景背景需按地点逐张重绘 | 现有场景画面是已人工维护的独立资产，不能批量覆盖或把设计意向记为已完成美术。 |
| 道具跟随鼠标的图块预先放进共享 HUD 预制体，并在使用时反复启停同一个对象 | 不在每次拖动时新建对象，保留以后直接调整图块样式的入口。 |
