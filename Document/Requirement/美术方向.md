# 《熄灯之后：48H》美术方向

2026-11-16 决定：后续画面采用锈湖式的诡谲绘本气质。这里记录本项目自己的执行规则；现有地点背景尚未逐张重绘，不能把方向变更记为背景美术已完成。

## 场景

- 保留固定视角、明确的可点击物轮廓和实验楼的真实空间关系；墙面、门框、窗、走廊透视参考实地照片，4F 玻璃连廊遵循 Demo 文档。
- 用低饱和棕、灰绿、灰蓝与暗红控制配色。白天仍能辨认现实材质，夜里以局部灯光和少量异常物打破画面的安静感。
- 人物使用项目内 `Assets/Resources/Characters/` 的透明图片作为轮廓，在对白中着深黑色；线索物、文字、谜题数字仍放在独立图层，确保可读。
- 对低 SAN 残影使用局部覆盖和短暂显影，保持真实线索与社团资料的视觉区分，不添加随机错误提示。
- 有独立透明抠图的可交互物使用黄色边缘高亮，具体绑定和未抠图素材的过渡规则见 `Document/Requirement/交互高亮规范.md`。

## UI

- UI 框使用 `Assets/Resources/UI/选择框.png` 直接拉伸；按钮使用 `Assets/Resources/S0/选项按钮.png` 直接拉伸。
- 背包格子是黑色半透明方块；没有图标时显示浅色名称。按钮与正文保持足够明暗对比。
- 对话框占屏幕下方约四分之一，人影立在框上方。具体尺寸、锚点和文字边距保留在预制体中由美术/UI 人员微调。

## 后续背景重绘范围

S0 的楼外、5F 活动室、走廊与 4F 入口；S1 的夜间活动室、走廊与入口；S2 的 4F 连廊三处及 5F 安全屋。各地点逐张替换时保留现有热点位置和日夜空间连续性，先复核场景中的人工修改，再处理背景资源。
