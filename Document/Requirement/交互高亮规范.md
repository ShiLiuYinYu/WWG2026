# 可交互物悬停高亮

2026-11-16 决定：有独立透明抠图的可交互物，鼠标悬停时以**物件轮廓的黄色高亮**提示交互，不显示覆盖物件的矩形色块。S0 活动室的第五把椅子是首个样例。尚未抠图的物件暂保留原有交互提示，等图片独立后逐个迁移。

## 接入方式

1. 将物件图片放在场景画面层，避免对白或弹窗关闭交互层时连图片一起隐藏。图片的 `Image.raycastTarget` 关闭。
2. 复制一层同位置、同尺寸、同 Sprite 的 `Image`，将其材质设为 `WWG/UI/Alpha Edge Highlight`，关闭 `raycastTarget` 和初始 `enabled`。材质按透明度提取内边缘，并用纯黄色绘制；按素材调整 `_Thickness`。
3. 保留独立的透明点击热点，给热点添加 `HotspotHoverOutline` 并把 `highlight` 指向描边层的 `Image`。热点只负责接收点击与悬停，不承载图片。
4. S0/S1 的 `Hotspot` 脚本检测到该组件后，不再显示矩形色块或悬停文字；移开鼠标、热点被禁用时关闭轮廓。未配置的热点维持现有行为。

首个绑定位于 `Assets/Scenes/S0/S0_ClubRoom.unity` 的 `ClubRoom Upper/ClubRoom Chair` 与 `Scene interactions/第五把椅子`。复用时先检查原素材是否真的具有透明轮廓，不能把整张未抠图背景当作高亮对象。

## 5F 走廊的固定物件

`S0_Corridor` 与 `S1_Corridor` 使用完整的亮灯／关灯底图，固定物件已经画在底图中，无需挖空或常态叠放抠图。四张 1920×1080 透明抠图仅用于悬停描边，放在 `Corridor Highlights` 画面层；对应的透明点击热点仍在交互层。此处的 `CorridorHoverOutline` 材质把 `_Thickness` 设为 `0.002`，适配整张画布的 UV 尺寸。

白天的安全出口牌、照明定时箱、楼层牌及活动室门均使用轮廓高亮；夜间仅活动室门原有对应切屏交互，另三个物件没有新增调查动作。其余没有独立抠图的切屏区域维持既有提示。

## 活动室台灯与纸箱

S0 台灯和柜顶纸箱、落地纸盒，S1 台灯、窗帘、落地纸盒与第五把椅子均由画面层图片和交互层透明热点组成。S1 仅在 P1 对位阶段允许拖放椅子，拖放时同时移动图片与热点；P1 完成后椅子固定在地胶框内，椅子和坐垫下工牌热点悬停时均显示同一黄色轮廓，点击椅子或坐垫可取得工牌。台灯、开帘图及活动室门的源文件虽然是 1920×1080 透明画布，Unity 导入后的 `Sprite.rect` 可能裁切到物件轮廓；画面尺寸按实际 Sprite 设置，开帘热点只覆盖帘子本身的 170×374 区域，避免整张画布挡住其他点击。关帘图 `左窗帘关闭1.png` 是 302×374 裁切图，在 S1 显示为 470×374 以盖住整扇窗，热点和描边同步拉伸；关帘描边使用 `CurtainClosedHoverOutline.mat`。柜顶纸箱的独立裁切图包含投影，`BoxHoverOutline` 以 alpha 阈值排除投影后描边。S0 活动室门新增返回走廊的透明热点；S1 门的轮廓高亮接在已有的玻璃调查热点上，原有返回走廊入口仍可使用。
